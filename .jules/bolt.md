## 2025-05-03 - [Bundle Size Bottleneck with React Icons and TinaCMS]
**Learning:** Found a specific client bundle size bottleneck where the entirety of `react-icons/bi` (~1.8MB) was being loaded into the main client chunk. This occurred because `components/icon.tsx` had `'use client'` and used `import * as BoxIcons from 'react-icons/bi'` to generate an `IconOptions` map for the TinaCMS `IconPickerInput`.
**Action:** Resolved by completely removing `import * as BoxIcons` from `components/icon.tsx` and dynamically loading it only when a "Bi" icon is needed using `next/dynamic`. The full map creation (`...BoxIcons`) was shifted to `tina/fields/icon.tsx`, which isolated the massive import from the frontend while preserving the full functionality of the CMS dynamic icon picker.
